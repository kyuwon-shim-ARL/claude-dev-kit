# Init.sh 커맨드 동기화 문제 해결 보고서

## 📅 수정 일시
2025-09-15

## 🔍 발견된 문제

### 1. 핵심 이슈
- init.sh가 **20개 커맨드**를 설치하려 시도
- 실제 GitHub 레포에는 **12개 커맨드**만 존재
- **8개는 폐기된 커맨드**로 다운로드 실패 후 빈 파일 생성

### 2. 폐기된 커맨드들 (8개)
```bash
# 더 이상 존재하지 않는 커맨드들:
- 안정화 (stabilize)
- 개발완료 (complete)
- 품질보증 (quality)
- 기획구현 (plandev)
- 극한검증 (extreme)
- 컨텍스트 (context)
- 주간보고, 문서정리, 레포정리
- 세션마감, 실험시작, 실험완료
- 보고서작업, TADD강화
```

### 3. 실제 존재하는 커맨드들 (12개)
```bash
- 기획, 구현, 검증, 배포, 전체사이클
- 분석, 실험, 보고, 연구, 찾기
- 테스트, 탐구
```

## ✅ 해결책 구현

### 1. init.sh 커맨드 목록 수정
```bash
# Before: 20개 커맨드 (8개 실패)
declare -A commands=(
    ["기획"]="plan"
    ["안정화"]="stabilize"  # ❌ 존재하지 않음
    # ... 총 20개
)

# After: 12개 실제 존재하는 커맨드만
declare -A commands=(
    ["기획"]="기획"
    ["구현"]="구현"
    # ... 총 12개 (모두 존재 확인됨)
)
```

### 2. 자동 동기화 시스템 구축

#### A. Python 동기화 스크립트
```python
# scripts/sync_init_commands.py
- .claude/commands/ 디렉토리 자동 스캔
- init.sh의 commands 배열 자동 업데이트
- 실제 파일과 스크립트 설정 100% 동기화
```

#### B. GitHub Actions 자동화
```yaml
# .github/workflows/sync-commands.yml
- 커맨드 파일 변경 감지
- 자동 sync 스크립트 실행
- 변경사항 자동 커밋
```

#### C. Git Pre-commit Hook
```bash
# .git/hooks/pre-commit 확장
- 커맨드 파일 변경 시 자동 동기화
- 스테이징에 init.sh 자동 추가
- 커밋 전 자동 검증
```
