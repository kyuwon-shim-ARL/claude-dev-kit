# /연구 - Research Project Manager

## 목적
바이오인포매틱스 및 데이터 분석 연구 프로젝트를 개발 코드와 독립적으로 관리하는 시스템

## 사용법

### 기본 커맨드
```bash
/연구 init [프로젝트명] [설명]     # 새 연구 프로젝트 시작
/연구 track                       # 현재 연구 진행사항 기록
/연구 milestone [이름]            # 주요 마일스톤 설정
/연구 reproduce [체크포인트]       # 특정 시점 재현
/연구 archive                     # 연구 완료 및 아카이빙
```

### 확장 커맨드 (제안)
```bash
# 탐색 단계
/연구 explore                    # 데이터 탐색 및 EDA
/연구 hypothesis [가설]           # 가설 설정 및 기록

# 실험 단계  
/연구 experiment [이름]           # 실험 시작 (자동 분기)
/연구 validate                    # 결과 검증 및 테스트

# 분석 단계
/연구 analyze                     # 결과 분석 (자동 저장)
/연구 compare [실험1] [실험2]     # 실험 결과 비교

# 도구 관리
/연구 tools                       # 사용 가능 도구 목록
/연구 checkpoint                  # 도구 개발 위한 체크포인트
/연구 resume                      # 체크포인트에서 재개

# 협업
/연구 share                       # 연구 결과 공유 준비
/연구 review [연구ID]             # 다른 연구 리뷰
```

## 핵심 기능

### 1. 독립적 연구 구조
```
research_projects/
├── 2024-09-09_drug_discovery/
│   ├── README.md              # 연구 개요
│   ├── timeline.md            # 자동 타임라인
│   ├── notebooks/             # Jupyter 노트북
│   ├── data/                  # 원본 데이터
│   ├── results/               # 분석 결과
│   ├── figures/               # 시각화
│   └── tools@ -> ../../src/   # 개발 도구 심링크
```

### 2. 자동 타임라인 추적
- 모든 분석 단계 자동 기록
- Git 커밋과 연동된 체크포인트
- 재현 가능한 환경 스냅샷

### 3. 연구-개발 분리
- 연구 프로젝트는 독립 디렉토리
- 개발 도구는 심링크로 연결
- 명확한 경계와 재사용성

## 구현 전략

### Phase 1: 기본 구조
1. 연구 프로젝트 템플릿 생성
2. 타임라인 추적 시스템
3. 기본 메타데이터 관리

### Phase 2: 고급 기능
1. 재현성 검증 시스템
2. 데이터 버전 관리
3. 결과 자동 문서화

### Phase 3: 통합
1. /분석 커맨드와 연동
2. 자동 보고서 생성
3. 협업 기능 추가

## 예상 효과
- **명확한 분리**: 도구 개발 vs 연구 분석
- **재현성 보장**: 모든 단계 추적 및 재현 가능
- **효율적 관리**: 자동화된 문서화 및 아카이빙
- **협업 용이**: 독립적 프로젝트로 공유 간편
